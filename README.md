# Yap (iOS)

Couch-to-5K for talking to camera. SwiftUI, iOS 17+.

## Develop
- Install: `brew install xcodegen`
- Generate + open: `make generate && open Yap.xcodeproj`
- Test: `make test`

Design system lives in `Yap/DesignSystem/` and is verified against `tokens.json`.
See `ROADMAP.md` for the plan and `docs/plans/` for milestone task lists.
