# M2 · Today + iOS Widget — Implementation Plan

> Logic-first per founder direction (2026-07-25): build the widget + its data core now; visual design is deferred. Uses brand **colors** (YapColor) but system fonts in the widget (custom-font-in-widget bundling deferred with design).

**Goal:** A home-screen WidgetKit widget shows a deterministic "prompt of the day" in three sizes, refreshes at local midnight, deep-links to Today via `yap://today`, and reflects the exact same prompt as the app (shared through the App Group `group.com.yap.shared`).

**Architecture:** A new `Shared/` source group compiled into **both** the `Yap` app and the `YapWidgetExtension` target. It holds the value types and logic both sides need: `Prompt`, `PromptLibrary` (curated seed list), `PromptProvider` (deterministic date→prompt), and `SharedStore` (App Group `UserDefaults` wrapper). The widget computes prompt-of-the-day via `PromptProvider` (always works, even before first launch) and the app also writes it to `SharedStore` so later shared values (streak, M6) have a home. The in-app `TodayView` is a minimal functional placeholder — the deep-link target — not a designed screen.

## Global constraints
- iOS 17+, Swift 6, SwiftUI/WidgetKit. XcodeGen; never hand-edit `.pbxproj`.
- App Group **`group.com.yap.shared`** (already on both targets from M0).
- Prompt-of-the-day selection is **deterministic and local-calendar-based**: stable within a day, advances at local midnight, wraps the library. Unit-tested.
- Design deferred: widget uses `YapColor` (purple/gold) + system fonts; no new visual polish.
- Simulator destination: `iPhone 17` (this machine's toolchain).
